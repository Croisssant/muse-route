# Layout Setup Pipeline

Automates the complete exhibit setup workflow for a museum layout in a single command.

## Overview

The `setup_layout_pipeline.py` script chains together three exhibit setup steps:

1. **Generate Exhibit List** - Creates exhibit CSV and JSON from input file
2. **Visualize Exhibits** - Generates color-coded visualization by section
3. **Generate Config Files** - Creates difficulty-specific validation configs

## Quick Start

```bash
# Setup a simple layout
python setup_layout_pipeline.py -c simple -l layout_01

# Setup a complex layout
python setup_layout_pipeline.py -c complex -l layout_03
```

## Prerequisites

Before running the pipeline, ensure your layout directory contains:

### Required Files

1. **exhibit_input.txt**
   - Format: `exhibit_range: Section` (e.g., `1-10: Greek`)
   - Defines which exhibits belong to which sections
   - See existing layouts for examples

2. **layout_annotations.json**
   - Generated from VIA annotation tool
   - Contains exhibit positions and gallery definitions
   - Use `convert_via_to_museum_layout.py` to create

3. **Layout Image** (auto-detected)
   - Either `{layout}.jpg` or `{layout}.png`
   - Base floorplan image for visualization

### Global Required File

- **exhibits_construction_helpers/data/selected_exhibits_preprocessed.csv**
  - Preprocessed museum artifact database
  - Must exist before running any layout pipeline

## Directory Structure

```
floorplans/{complexity}/{layout}/
├── exhibit_input.txt             [INPUT - Required]
├── layout_annotations.json       [INPUT - Required]
├── {layout}.jpg or .png         [INPUT - Required, auto-detected]
│
├── exhibits.csv                  [OUTPUT - Generated by Step 1]
├── exhibit_list.json            [OUTPUT - Generated by Step 1]
├── exhibit_visualization.png    [OUTPUT - Generated by Step 2]
├── easy_spatial.json            [OUTPUT - Generated by Step 3]
├── easy_semantic.json           [OUTPUT - Generated by Step 3]
├── medium.json                  [OUTPUT - Generated by Step 3]
└── hard.json                    [OUTPUT - Generated by Step 3]
```

## Pipeline Steps

### Step 1: Generate Exhibit List

**Command:**

```bash
python exhibits_construction_helpers/generate_exhibit_list.py
  -i {layout_dir}/exhibit_input.txt
  -c exhibits_construction_helpers/data/selected_exhibits_preprocessed.csv
  -o {layout_dir}/exhibits.csv
  -j {layout_dir}
```

**Output:**

- `exhibits.csv` - Full exhibit data with exhibit numbers
- `exhibit_list.json` - Exhibit descriptions for display

**What it does:**

- Parses exhibit_input.txt assignments
- Validates sufficient artifacts available
- Maps exhibit numbers to unique artifacts
- Prevents duplicate artifact usage

### Step 2: Visualize Exhibits by Section

**Command:**

```bash
python exhibits_construction_helpers/visualize_exhibits_by_section.py
  -f {layout_dir}/{layout}.{jpg|png}
  -a {layout_dir}/layout_annotations.json
  -c {layout_dir}/exhibits.csv
  -o {layout_dir}/exhibit_visualization.png
```

**Output:**

- `exhibit_visualization.png` - Color-coded exhibit map with legend

**What it does:**

- Overlays exhibit positions on floorplan
- Colors exhibits by section/category
- Adds legend with section colors
- Helps verify exhibit distribution

### Step 3: Generate Config Files

**Command:**

```bash
python exhibits_construction_helpers/generate_config_files.py
  -l {layout_dir}
  -c exhibits.csv
```

**Output:**

- `easy_spatial.json` - Spatial constraints only
- `easy_semantic.json` - Semantic constraints only
- `medium.json` - Mixed constraints (~10 exhibits)
- `hard.json` - All constraints (~25 exhibits)

**What it does:**

- Analyzes exhibit attributes (materials, techniques, locations, dates)
- Generates difficulty-appropriate constraints
- Sets gallery must_see/restricted configs
- Uses least common values for easy, most common for hard

## Command-Line Arguments

| Argument       | Short | Required | Description                                  |

## Validation Checks

The pipeline validates:

1. ✅ `exhibit_input.txt` exists
2. ✅ `layout_annotations.json` exists
3. ✅ `selected_exhibits_preprocessed.csv` exists
4. ✅ Layout image exists (.jpg or .png - auto-detected)
5. ✅ Each script completes successfully

If any check fails, the pipeline stops with a clear error message.

```bash
  --route [your_route.json]
```

## Troubleshooting

### "Missing: exhibit_input.txt"

**Cause:** No exhibit_input.txt file in the layout directory

**Solution:** Create an exhibit_input.txt file with format:

```
1-10: Greek
11-20: Roman
21-30: Egyptian
```

### "Missing: layout image"

**Cause:** No .jpg or .png file matching layout name

**Solution:**

- Ensure image is named exactly `{layout}.jpg` or `{layout}.png`
- Check the layout name matches the directory name

### "Missing: selected_exhibits_preprocessed.csv"

**Cause:** Global exhibit database not found

**Solution:** Ensure `exhibits_construction_helpers/data/selected_exhibits_preprocessed.csv` exists

### "Step 1 failed"

**Cause:** Insufficient artifacts in database for requested sections

**Solution:**

- Check section names in exhibit_input.txt match database
- Reduce number of exhibits requested
- Verify CSV has enough artifacts per section

### "Step 2 failed"

**Cause:** Image processing or annotation mismatch

**Solution:**

- Verify layout_annotations.json is valid
- Check image file is readable
- Ensure exhibit numbers in CSV match annotations

### "Step 3 failed"

**Cause:** CSV missing required columns

**Solution:**

- Ensure exhibits.csv has all required columns
- Re-run Step 1 to regenerate CSV

## Exit Codes

- **0** - Success: All steps completed
- **1** - Failure: One or more steps failed or validation error

Use in scripts:

```bash
python setup_layout_pipeline.py -c simple -l layout_01
if [ $? -eq 0 ]; then
    echo "Pipeline succeeded!"
else
    echo "Pipeline failed!"
fi
```

## Configuration Files Generated

Each config file follows this structure and difficulty level:

### easy_spatial.json

- All galleries: `"must_see"`
- Exhibits required: 1
- No attribute constraints

### easy_semantic.json

- No gallery constraints
- Exhibits required: 1
- ONE attribute constraint (least common value)

### medium.json

- All galleries: `"must_see"`
- Exhibits required: ~10
- One category + 2-3 attribute constraints (most common values)

### hard.json

- All galleries: `"must_see"`
- Exhibits required: ~25
- Multiple categories + specific exhibits + all attribute types

## Tips

1. **Verify Exhibit Distribution**: Check `exhibit_visualization.png` to ensure exhibits are well-distributed across sections

2. **Test Incrementally**: Run pipeline on simple layouts first before complex ones

3. **Rerun if Needed**: Pipeline is idempotent - safe to run multiple times (overwrites previous output)

4. **Check CSV Quality**: Open `exhibits.csv` to verify all exhibit data looks correct

5. **Validate Configs**: Test each generated config file with actual route validation
